Kết nối Google Sheets (lưu và xem điểm)
Tải file mẫu (CSV)
  1. Mở Google Sheets, chọn Tiện ích mở rộng › Apps Script. Xóa mã cũ, dán mã bên dưới, bấm Lưu.
  2. Lần đầu: Triển khai › Tùy chọn triển khai mới › Ứng dụng web; Thực thi: Tôi; Quyền truy cập: Bất kỳ ai.
  3. Đã cài trước đây: Triển khai › Quản lý các lần triển khai › Sửa (bút chì) › Phiên bản: Phiên bản mới › Triển khai — giữ nguyên URL.
  4. Lưu ý: nút Lưu và Chạy trong trình soạn thảo chưa làm app thay đổi — chỉ Triển khai phiên bản mới mới có hiệu lực. Muốn kiểm tra, chọn hàm kiemTraCaiDat rồi bấm Chạy (không ghi, không xóa gì).

Mã đã có sẵn mã đọc dữ liệu của bạn (ô "Mã đọc dữ liệu" ở Bước 2): chỉ ai có mã mới xem được điểm học sinh. Mỗi năm học, điểm được ghi vào một tab riêng (ví dụ "2026-2027").

Dùng máy khác? Nhập đúng mã đang có trong Apps Script. Đổi mã thì phải dán lại mã Apps Script và triển khai phiên bản mới.

Công cụ trong Apps Script (chọn tên hàm ở thanh công cụ rồi bấm "Chạy")
  • saoLuu: tạo bản sao toàn bộ Google Sheet trong Drive của bạn. Nên chạy mỗi cuối học kỳ.
  • xoaBaiNopTrung: xóa các bài bị ghi trùng (giống hệt, cách nhau dưới 2 phút). Nên chạy saoLuu trước.
AI dự phòng (tùy chọn)

Robot dùng DeepSeek (kết nối ở trang chủ). Khi DeepSeek lỗi hoặc hết hạn mức, Robot thử các dịch vụ dưới đây nếu bạn nhập key. Key chỉ lưu trên máy này.

Đăng đề lên GitHub (gửi link cho học sinh)
⚠️ Bạn đang mở bản web. Vì an toàn, chỉ nhập token GitHub trên phần mềm chạy ở máy tính (mở bằng MO_TOOL_GIAO_DUC.bat): các trang GitHub Pages của cùng một tài khoản dùng chung bộ nhớ trình duyệt.

Mỗi môn có một kho riêng đã tạo sẵn (đã bật GitHub Pages). Khi đăng đề, bạn chỉ cần chọn kho theo môn và đặt tên đề — phần mềm tự tải lên và đưa ra link + mã QR.

Hướng dẫn tạo token (làm một lần, khoảng 2 phút)
  1. GitHub › ảnh đại diện › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Expiration: 1 năm · Repository access: Only select repositories › chọn các kho kttx-… (9 kho) · Permissions › Repository permissions › Contents: Read and write.
  3. Bấm Generate token, sao chép token (bắt đầu bằng github_pat_), dán vào ô bên dưới rồi bấm Lưu & kiểm tra.

Lưu ý: kho công khai nên ai có link đều xem được đề (kể cả đáp án trong mã trang). Hãy gỡ đề sau khi thi xong. Không dùng chung token này với kho mã nguồn phần mềm.
