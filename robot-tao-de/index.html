Tải File Mẫu (CSV)

Tạo một Google Sheets mới (hoặc import file mẫu CSV). Chọn Tiện ích mở rộng > Apps Script. Dán toàn bộ đoạn mã sau thay thế code cũ, sau đó bấm Triển khai (Deploy) > Tùy chọn triển khai mới > Loại: Ứng dụng web (Ai cũng có quyền truy cập).

Copy đường link Web App URL sinh ra sau khi Deploy và dán vào ô dưới đây. Link này sẽ đảm nhiệm cả việc gửi điểm và vẽ biểu đồ.
